# Swiper 14.3.0

Swiper is loaded locally on About for the ingredient and history carousels, on Our Tea for the hero backgrounds, new drink photos, backgrounds and mobile labels, and on People for the Foundations cards and Moments photo marquee. It provides fade transitions, looping, touch input and autoplay without a jQuery dependency.

Documentation: https://swiperjs.com/swiper-api
