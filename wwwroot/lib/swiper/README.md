# Swiper 14.3.0

Swiper is loaded locally on About for the ingredient and history carousels, on Our Tea for the hero backgrounds, new drink photos, backgrounds and mobile labels, on People for the Foundations cards and Moments photo marquee, and on Connections for the centered In Action gallery. It provides fade transitions, looping, touch input and autoplay without a jQuery dependency.
